Elementor Has_Meta Trait Documentation

Documentation for the Has_Meta trait in Elementor's Atomic Widgets module

Overview

The Has_Meta trait is part of Elementor's Atomic Widgets module, specifically within the PropTypes system. This trait provides functionality for storing and retrieving metadata associated with prop types in Elementor's widget components.

The trait is defined in the Elementor\Modules\AtomicWidgets\PropTypes\Concerns namespace and works alongside other prop type components to provide a comprehensive typing system for Elementor's atomic widgets architecture.

Properties

protected array $meta = [];

A protected array property that stores metadata as key-value pairs. This property is initialized as an empty array.

Methods

public function meta($key, $value = null): self

Sets a metadata value for a specific key. This method is a fluent setter, allowing method chaining.

$key: The metadata key, or a tuple array containing [key, value]
$value: The metadata value (optional if $key is a tuple array)
Return value: $this (for method chaining)

Example Usage:

// Option 1: Key and value as separate parameters
$propType->meta('required', true);

// Option 2: Key and value as a tuple array
$propType->meta(['required', true]);
public function get_meta(): array

Retrieves the entire metadata array.

Return value: array - The complete metadata array

Example Usage:

$allMetadata = $propType->get_meta();
public function get_meta_item($key, $default = null)

Retrieves a specific metadata value by key. Returns a default value if the key doesn't exist.

$key: The metadata key to retrieve
$default: The default value to return if the key doesn't exist (default: null)
Return value: The metadata value or the default value

Example Usage:

// Get the 'required' metadata with a default of false
$isRequired = $propType->get_meta_item('required', false);

Common Use Cases

Storing Validation Rules

The Has_Meta trait is often used to store validation rules for prop types: 

$stringProp = (new String_Prop())
    ->meta('required', true)
    ->meta('min_length', 5)
    ->meta('max_length', 100);

Storing UI Hints

Metadata can be used to provide hints for the user interface: 

$colorProp = (new Color_Prop())
    ->meta('default', '#ff0000')
    ->meta('alpha', true)
    ->meta('palette', ['#ff0000', '#00ff00', '#0000ff']);

Accessing Metadata

To access metadata during widget rendering or validation: 

// Check if a prop is required
$isRequired = $prop->get_meta_item('required', false);

// Get all metadata
$allMeta = $prop->get_meta();

// Check for a specific palette
$hasPalette = isset($allMeta['palette']);

Notes and Best Practices

Integration with Prop Types

The Has_Meta trait is designed to be used with classes that implement the Prop_Type interface in Elementor's atomic widgets system. It provides a standardized way to store and retrieve metadata for prop types.

Fluent Interface

The meta() method implements a fluent interface pattern, allowing for method chaining to set multiple metadata values in a single expression.

Tuple Syntax

The trait supports both standard parameter passing and tuple syntax ([key, value]) for setting metadata, providing flexibility in how metadata is defined.
