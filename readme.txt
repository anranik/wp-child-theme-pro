Create and customize child themes for any WordPress theme with just a few clicks.

== Description ==

WP Child Theme Pro allows you to easily create child themes for any WordPress theme. You can customize CSS, JavaScript, and other theme files without losing your changes when the parent theme is updated.

Features:
* One-click child theme creation
* CSS and JavaScript customization
* Theme file editor
* Backup and restore functionality
* Import and export child themes

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wp-child-theme-pro` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Appearance->Child Theme Pro screen to create and customize child themes

== Frequently Asked Questions ==

= What is a child theme? =

A child theme is a theme that inherits the functionality and styling of another theme, called the parent theme. Child themes allow you to modify an existing theme without losing your changes when the parent theme is updated.

= Can I create a child theme for any WordPress theme? =

Yes, you can create a child theme for any WordPress theme that follows the WordPress theme standards.
